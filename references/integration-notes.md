# Integration boundaries

The unified entry point combines 82 canonical modules from agent-toolkit and workflow-skills: 43 and 39 respectively. Distribution copies remain as archived resources but do not receive duplicate catalog entries. Every archived definition is named MODULE.md; only the root is named SKILL.md.

Both local source trees are preserved under sources, including licenses and helper resources. Context Mode is excluded from this bundle. Existing installed skills and MCP configuration are outside this local integration.

The integration adds task routing, conflict resolution, progressive loading, invocation boundaries, dependency checks, platform adaptation, and a catalog. Local Markdown links were adapted to MODULE.md. Eighty canonical procedure bodies otherwise match their originals; code-review and implement-spec were intentionally adapted for working-tree review and local setup aliases. The original repositories outside this bundle retain the source versions. Individual procedures can still require their own CLI tools or external integrations.

To use the result, load the root SKILL.md and resolve its catalog locally. Install the complete folder so its references and scripts remain available. Archived MODULE.md files are supporting procedures rather than independently discoverable skills. Review the preserved licenses before redistribution.
