# Project continuity

For substantial work in this project, read `SKILL.md` and the latest `.ucm/checkpoints/` entry before editing. After a meaningful milestone or before handing work to another agent, run `scripts/ucm.mjs validate --stdin` and save a passing checkpoint with `scripts/ucm.mjs`. Never record credentials or raw transcripts. On resume, review the freshness report, verify referenced files, and claim a handoff before becoming the sole writer.
